# Hn38videoAItool

Desktop Windows Flow tool for Meta AI.

Flows: Văn bản → Ảnh; Ảnh → Ảnh; Ảnh → Ảnh → Ảnh; Văn bản → Video; Ảnh → Video.

The browser uses a persistent local profile. The user signs in directly; the app does not request passwords, OTPs or cookies.

Build from GitHub Actions: run `Build Hn38videoAItool Windows` and download the artifact.
